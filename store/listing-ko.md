# ytdownForAND 등록정보 초안

판매자·국가·가격·연령 등급·개인정보처리자와 연락처는 미확정입니다. 실제 콘솔 입력 기준으로 확정하세요.

## 짧은 설명

권한이 있는 미디어의 저장과 대기열을 관리합니다.

## 상세 설명

다운로드할 권한이 있는 미디어만 이용하세요. 지원 사이트·화질·오디오 저장·인증은 서비스 환경과 권리 조건에 따라 제한됩니다. 스토어용 설명은 서비스 약관·권리 및 네이티브 라이선스 확인 후 확정해야 합니다.

## 권한과 데이터 안내 / 심사 노트

네트워크·알림·다운로드용 포그라운드 서비스와 구형 Android 저장소 권한을 사용합니다. 로그인 세션은 민감정보이므로 노출하지 마세요. 스토어 배포 검토 전 제출하지 마세요.

앱 메인화면의 `개인정보·권한 안내`에서 고지를 읽을 수 있습니다. 권한 없이도 안내를 읽을 수 있으며 필요한 기능만 제한됩니다. 권한을 거절한 상태와 허용한 상태를 모두 심사해 주세요.

## 제출할 자료

1. 확정된 앱 이름/카테고리/연령 등급/지원 국가/무료 또는 유료 정책.
2. 실제 판매자명과 공개 고객지원 메일, 공개 HTTPS 개인정보처리방침 URL.
3. 정식 배포키로 서명한 `storeRelease` APK. 기존 APK와 ID/키가 다르면 데이터 이전 방식을 안내합니다.
4. 실제 앱 화면의 개인정보 없는 스크린샷, 자체 제작 아이콘/그래픽. 이미지 픽셀·개수·형식은 등록 시 콘솔과 공식 이미지 가이드에서 확인합니다.
5. 권한 허용·해제와 핵심 기능의 재현 절차, 알려진 기기별 제한. 실제 개인정보가 있는 계정·스크린샷·인증정보는 제출 자료에 포함하지 않습니다.
6. 의존성·글꼴·아이콘·외부 서비스·다운로드 콘텐츠의 사용/재배포 권리 확인.

무료·광고 없음 등 아직 정하지 않은 조건을 확정 사실처럼 홍보하지 않습니다. 타 스토어 이동 유도 문구·무관한 키워드·완전 호환 보장 문구를 넣지 않습니다.
