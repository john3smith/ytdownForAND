# YTDown for Android

**YouTube·X·Instagram의 영상과 사진을 Android 기기에 저장하는 앱**입니다. 공유 메뉴로 링크를 보내거나 직접 입력하고, 대기열·계정 연속 다운로드·M4A 음원 추출을 사용할 수 있습니다.

- [처음 사용하는 분을 위한 설명서](USER_GUIDE.md)
- [APK 다운로드 및 버전별 변경사항](https://github.com/john3smith/ytdownForAND/releases)

## v1.9.17 음원만 추출

- `음원만 추출 (M4A)` 토글을 추가했습니다. 최초 기본값은 **OFF**이며 변경한 설정은 기기에 저장됩니다.
- ON이면 오디오 스트림을 우선 다운로드하고 기존 FFmpeg로 M4A만 저장합니다. 음원이 영상과 합쳐진 경우에는 임시 영상에서 음원을 추출하고 임시 영상을 제거합니다.
- 음원 모드에서는 사진 저장과 직접 동영상 저장 폴백을 실행하지 않습니다. 사진 전용/무음 게시물은 추출 실패로 표시합니다.
- 일반 링크, 공유 링크, 대기열, 계정 연속 다운로드 모두 등록 시점의 설정을 유지합니다. 대기 중 토글을 바꿔도 이미 등록한 작업은 바뀌지 않습니다.
- 영상 화질 선택은 음원 모드에서 비활성화되며, OFF로 돌아가면 기존 영상·사진 다운로드가 유지됩니다.
- `Download/YTDown`에 `제목 [ID]-순번-audio.m4a`로 저장해 기존 영상 파일과 분리합니다.

## v1.9.16 계정 다운로드 대기열

- 계정 다운로드도 일반 링크와 같은 순서의 대기열 한 칸으로 등록됩니다.
- 실행 중인 계정은 대기열 목록에 `미디어 검색 중` 또는 `다운로드 완료 항목/전체 항목`으로 계속 표시됩니다.
- 계정 검색/다운로드 중 공유한 다른 링크는 뒤에 대기하며, 계정 작업 완료/검색 실패 후 순서대로 실행됩니다.
- 검색 완료 전에 네트워크 콜백이 빈 미디어 목록을 완료 처리하지 않도록 검색 상태를 구분합니다.
- 목록에서 계정 항목만 취소하면 다른 대기 링크는 유지됩니다. 기존 두 번 누르는 전체 취소 버튼은 전체 작업/대기열을 취소합니다.
- 대기열은 현재 앱 실행 세션 내 메모리에 유지됩니다. 강제 종료/프로세스 종료 후 복원 기능은 제공하지 않습니다.

## v1.9.15 대기열 및 Wi-Fi 시작 설정

- 일반 링크는 최대 10개까지 대기할 수 있습니다. `대기열 보기`에서 대기 항목을 확인하고 하나씩 취소할 수 있습니다.
- `Wi-Fi에서만 다운로드 시작`은 기본 OFF입니다. ON 상태에서 Wi-Fi가 아니면 일반 링크는 대기열에 보관되며, Wi-Fi가 연결되면 시작합니다. 계정 전체 다운로드는 Wi-Fi 연결 후 시작할 수 있습니다.
- 이 설정은 새 다운로드의 **시작 시점**에 적용됩니다. 이미 시작한 다운로드는 Wi-Fi가 끊겨도 자동으로 중단하지 않습니다.

YouTube, X(트위터), Instagram 링크를 입력하거나 다른 앱에서 공유하면 사진 또는 동영상을 다운로드하는 로컬 Android 앱입니다.

## 설치

`YTDown-v1.9.20-arm64-debug.apk`를 Android 휴대폰으로 옮긴 뒤 설치합니다. Play 스토어 외부 APK 설치 권한이 필요합니다.

앱을 열면 다운로드 전에 최신 stable `yt-dlp`를 확인하고 자동으로 업데이트합니다.
다른 앱의 공유 메뉴에서 링크를 보내면 영상 이름을 확인한 뒤 다운로드를 자동으로 시작합니다.
공유 대상 앱 안에 머무르지 않고 YTDown 앱 작업을 전면에 엽니다.
`바로 다운로드` 스위치는 기본으로 켜져 있으며, 끄면 공유 또는 클립보드에서 받은 링크를 입력칸에만 채우고 자동 다운로드는 시작하지 않습니다.
다운로드 중에는 시스템 알림에 영상 이름과 진행률이 표시됩니다.
다운로드 작업이 성공, 실패, 취소 또는 백그라운드 제한으로 종료되면 관련 알림은 알림창에서 자동으로 제거됩니다.
다운로드가 끝날 때까지 포그라운드 서비스와 CPU 절전 방지를 유지하므로 앱을 백그라운드로 보내거나 화면을 꺼도 작업이 계속됩니다.
다운로드 중 멀티윈도우로 전환하거나 창 크기를 조절해도 Activity를 재생성하지 않아 진행 상태가 유지됩니다.
화면 상단의 작은 `i` 버튼에서 일반·공유·계정 전체 다운로드와 취소 방법을 확인할 수 있습니다.
다운로드 중 새 링크를 입력하거나 공유하면 최대 10개까지 대기열에 추가되며 순서대로 실행됩니다.
취소 버튼을 1초 안에 두 번 누르면 현재 진행 중인 정보 조회, 사진/영상 다운로드와 남은 대기열을 함께 중단합니다.
`X·Instagram 계정 전체 미디어` 버튼은 입력한 X 게시물·프로필 또는 Instagram 게시물·프로필·릴스 탭의 계정을 확인하고,
각 사이트에 저장된 로그인 세션으로 계정의 미디어 게시물을 끝까지 조회합니다.
X 프로필 기본 탭으로 이동된 경우 미디어 탭을 자동으로 다시 선택하며,
민감한 콘텐츠 경고가 표시되면 프로필 보기 버튼을 자동 승인하고 검색을 계속합니다.
Instagram은 프로필과 릴스 탭을 차례로 끝까지 스크롤하면서 화면 링크와 로그인된 타임라인 응답을 함께 분석합니다. 최신 `/api/graphql` 응답도 검사하며 중복 게시물은 한 번만 다운로드합니다. 다음 페이지가 남았는데 스크롤·시간 제한으로 목록을 끝까지 읽지 못했다면 부분 목록을 전체 결과로 취급하지 않고 진단 로그와 함께 중단합니다.
두 사이트 모두 미디어 타임라인 응답에서도 게시물을 직접 찾아 화면 구조 변경에 대응합니다.
계정 검색이 실패하면 인증, 네트워크 요청 및 화면 상태가 포함된 진단 로그를 표시하며
`로그 복사` 버튼으로 내용을 복사할 수 있습니다. 쿠키 값은 로그에 포함하지 않습니다.
찾은 미디어 게시물을 최신순으로 다운로드하며,
각 다운로드가 완료되면 다음 게시물을 바로 시작합니다.
계정 연속 다운로드가 끝나면 앱 상태 문구에 해당 계정 아이디를 표시합니다.
대기열 및 계정 연속 다운로드 중에는 항목 사이에서도 백그라운드 서비스를 유지합니다.
이 기능을 사용하기 전에 앱의 로그인 항목에서 다운로드할 사이트의 로그인을 완료해야 합니다.

Android 15 이상에서는 운영체제 정책상 `dataSync` 백그라운드 작업이 24시간 중 최대 6시간으로 제한됩니다.

## 저장 위치

휴대폰 공용 다운로드 폴더의 `Download/YTDown`에 저장됩니다.

## 지원 범위

- Android 7.0 이상
- ARM64 기기
- 공개 YouTube 영상
- 공개 X(트위터) 사진 및 동영상 게시물
- 공개 Instagram 사진, 여러 장 사진 게시물, 릴스 및 동영상 게시물
- 로그인한 계정으로 접근 가능한 X 및 Instagram 계정의 전체 미디어 연속 다운로드
- 최고 화질, 1080p 이하, 720p 이하

검증(2026-09-29): Instagram 게시물 링크에서 계정 @dungbelle_를 찾은 뒤
7개 게시물의 원본 크기 사진 12장을 저장했습니다(7개 성공, 0개 실패).
사진과 캐러셀을 릴스로 잘못 분류하지 않도록 실제 미디어 유형을 우선합니다.
다른 계정의 실제 영상·릴스까지 모두 저장되는지는 아직 별도 검증이 필요합니다.

비공개 게시물은 앱의 사이트별 로그인 화면에서 접근 권한이 있는 계정으로 로그인한 경우 다운로드할 수 있습니다. DRM, 유료 콘텐츠, 일부 연령 제한 콘텐츠 및 계정에 접근 권한이 없는 게시물은 지원하지 않습니다. 저작권을 보유했거나 다운로드 허가를 받은 영상에만 사용해야 합니다.

X 공개 API가 민감한 이미지 게시물을 `TweetTombstone`으로 반환하는 경우에는 비로그인 게시물 페이지와 저장된 로그인 세션을 차례로 조회해 원본 사진 주소를 복구합니다.
저장된 X 로그인 쿠키가 있으면 `TweetResultByRestId` 로그인 응답에서 민감 콘텐츠와 인용 게시물의 실제 사진·동영상 주소를 우선 복구합니다.
