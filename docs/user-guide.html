YTDown for Android

1.9.27 · debug APKAndroid 7.0 이상 · ARM64 휴대폰

YouTube 영상과 X·Instagram 게시물의 사진·동영상을 휴대폰에 저장하는 앱입니다. 지원 계정 미디어를 대기열에 넣거나 음원만 M4A로 추출할 수 있습니다. Windows판과는 별도 앱입니다.

미완료 파일 조회 / 삭제

메인 화면 아래 버튼을 누르면 미완료 파일의 이름·용량·수정 시각·저장 위치가 표시됩니다. 항목을 눌러 개별 삭제하거나 전체 삭제를 누른 뒤 확인하세요. 삭제는 영구적이며 이어받기가 불가능해집니다.

다운로드·계정 검색·대기열을 종료한 상태에서만 이용할 수 있습니다. .part·조각·.ytdl 재개 정보 및 앱이 만든 저장 미완료 항목만 검사합니다. 완료 파일이나 완료 여부가 불확실한 일반 영상 파일은 지우지 않습니다. 접근 불가 저장소는 따로 안내하며, 삭제 직전에 바뀐 파일은 건너뜁니다.

01

어떤 일을 하나요?

영상·사진 저장

지원 게시물의 여러 미디어를 검사하고 최고 화질·1080p 이하·720p 이하를 선택합니다.

음원 전용

음원만 추출(M4A) 토글로 오디오만 저장합니다. 최초 기본값은 OFF입니다.

계정·대기열

최대 10개 대기열과 개별 취소를 제공합니다. 계정 검색 중에도 계정 작업이 대기열에 유지됩니다.

진행·웹페이지

다운로드 진행률, 현재 웹페이지 보기, 최근 1일 로그와 Wi-Fi에서만 시작 옵션을 제공합니다.

02

처음 사용하기

  1. Releases에서 기기에 맞는 APK의 게시 여부·버전·서명을 확인해 설치합니다. 휴대폰 ARM64와 에뮬레이터 x86_64를 구분하세요.
  2. 엔진 준비를 기다리고 필요할 때 저장·알림 권한을 허용합니다.
  3. 주소를 붙여넣거나 다른 앱의 공유에서 YTDown을 선택합니다.
  4. 사진·동영상 또는 음원 모드를 정하고 다운로드를 시작합니다.
  5. 완료 상태와 Download/YTDown의 생성 파일을 확인합니다. 다운로드 시작은 완료가 아닙니다.
03

자주 쓰는 기능

게시물
지원 게시물의 여러 사진·영상도 처리합니다. 일부 항목 실패 여부는 결과와 로그를 확인하세요.
계정 다운로드
지원 사이트 로그인 메뉴에서 직접 로그인한 뒤 계정·프로필·지원 릴스 탭 링크로 계정 전체 미디어를 선택합니다.
대기열
대기열 보기에서 상태를 보거나 개별 취소합니다. 전체 취소는 1초 안에 두 번 눌러 현재 작업과 대기 작업을 중단합니다.
진행률과 네트워크
FFmpeg 저장은 영상 길이가 있으면 처리 시간 기준 퍼센트, 없으면 저장 시간·용량을 표시합니다. Wi-Fi 전용 시작은 이미 시작한 작업을 자동 중단하지 않습니다.
04

문제가 생겼을 때

퍼센트가 없습니다
전체 길이를 얻지 못하는 스트림은 시간·용량만 표시할 수 있습니다. 저장 검증까지 끝나야 최종 100%가 됩니다.
계정 수집이 멈춥니다
로그인 상태·사이트 응답·남은 저장공간·최근 로그를 확인하세요. 모든 계정 전체 수집을 보장하지 않습니다.
APK 설치가 안 됩니다
기기 ABI와 서명을 확인하세요. 서명 불일치만으로 데이터 삭제를 바로 진행하지 마세요.
05

데이터와 보안

  • 로그에는 URL·작성자·파일명이 포함될 수 있으므로 공유 전에 확인하세요. 로그인 세션과 개인 미디어는 Git에 올리지 마세요.
  • 웹페이지 보기와 로그인 저장 메뉴는 다릅니다. 인증서 경고·나이 확인·추가 인증을 자동 생략하지 않습니다.
06

알아두실 제한사항

  • 대기열은 앱 프로세스 메모리에 있어 강제 종료·재부팅 후 복원되지 않습니다.
  • 사이트 변경·로그인 만료·DRM·접근 권한 때문에 실패할 수 있습니다. 다운로드 권한이 있는 콘텐츠만 사용하세요.
  • 등록 당시 화질·음원·연결 설정을 각 작업이 유지합니다. 나중에 토글을 바꿔도 기존 대기 항목은 바뀌지 않습니다.
  • 1.9.27부터 beta 표기를 제거했습니다. debug 서명과 실제 검증 범위는 별개이며 사이트별 인증/네트워크 제한은 남을 수 있습니다.
